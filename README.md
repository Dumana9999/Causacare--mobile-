
# CausaCare Mobile

Open-source software for free mobile healthcare services in Bulgaria.

## Our Mission
CausaCare Mobile supports five fully equipped mobile medical clinics serving elderly people in Burgas and Sliven.

All medical examinations and home visits will be completely free for patients.

## Features
- QR code appointment booking
- Mobile clinic scheduling
- Home visit requests
- Village visit planning
- Bulgarian-language interface
- Patient privacy and data protection

## Organization
CausaCare Foundation (Bulgaria)

## Status
Open-source project in development.
